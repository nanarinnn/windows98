# Transcript 관리

이 디렉터리는 원본 전사와 사람의 검수 자료를 별도로 보관하는 계층이다. 저장소 루트의 `1화.txt`~`10화.txt`를 삭제·이동하거나 자동으로 대체하지 않는다.

## 디렉터리와 검수 상태

| 디렉터리 | 상태 | 용도 |
| --- | --- | --- |
| `raw/` | RAW | 원본 AI 전사본. 원문의 오류가 보여도 임의 수정하지 않는다. |
| `reviewed/` | REVIEWED | 사람이 확인하여 확정한 검수본. |
| `partial/` | PARTIALLY_REVIEWED | 일부만 사람이 검수했으며 아직 전체가 확정되지 않은 전사본. |

## 자료 사용과 보존 원칙

- AI가 불명확한 음성을 추측하여 canon(정식 설정)으로 확정하지 않는다.
- RAW 파일을 검수본으로 덮어쓰지 않는다. 원본을 보존하고 검수본은 별도 파일로 저장한다.
- 게임의 수칙·스토리·대사 수정 시 REVIEWED 자료를 우선 source of truth(기준 자료)로 사용한다. 자료가 있다는 이유만으로 게임 내용을 자동 변경하지 않는다.
- PARTIALLY_REVIEWED의 미확정 부분은 게임의 새로운 정식 설정으로 확정하지 않는다. 검수된 범위와 미확정 범위를 명시한다.
- 자료별로 에피소드, 출처, 검수 상태, 검수 범위와 불확실한 구간을 기록한다. 사람이 확정하지 않은 자료를 REVIEWED로 승격하지 않는다.
- 자료 추가·변경 시 변경 이유와 검수 상태를 루트 `CHANGELOG_AI.md`에 기록한다.

### EP02 reviewed 갱신 (2026-10-05)

`reviewed/EP02_서울_심야_2호선.txt`는 사용자가 원문을 다시 청취해 확정한 교정을 반영한 판으로 교체했다(출처: 사용자 제공 `D:YUYEONwindows98	ext_original_etcEP02_서울_심야_2호선_reviewed.txt`). 이 파일만 ZIP 원본과 바이트가 다르며 `raw/`는 그대로다. 확정 사항: 심야 승객, 생환자 및 이탈 실패자·사망자의 유해, 절단·압착·원인 불명의 실종, 조명과 조명 사이 구간, 봉합, 얇은 것의 진입, 오른손 전두엽(원문 그대로, 다른 부위로 바꾸지 않음), 다음 칸, 천장까지, 객차 진입 통로, 그리고 명백한 STT 오류 정리(객체→객차 등). **05:31 "신설동행이라고 말한 승객은 [문장 일부 삭제] 사례가 확인되었습니다."는 원문에서 문장 일부가 의도적으로 삭제된 연출이며 별도 대응 규칙이 아니다** — 내용을 추측·복원하지 않고, 행선지 질문의 규칙은 "어떠한 대답도 하지 말고 손으로 노선도를 가리킨다"뿐이다. 이 문서의 내용은 `2화.txt`, Story 문서 창, Field EP02의 상위 canon이다.
